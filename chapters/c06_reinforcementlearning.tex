\chapter{Reinforcement Learning}
\label{chap:reinforcement-learning}
\minitoc

Learning in an interactive environment requires more than 
 deriving a fixed mapping from inputs to outputs. 
% 
An autonomous agent must repeatedly decide how to act, 
 observe the consequences of its decisions, 
 and adapt its future behavior accordingly. 
% 
These decisions are inherently sequential: 
 an action may provide little immediate benefit 
 while substantially affecting the outcomes that can be obtained later.

\glsentryfull{RL} provides a framework for addressing this form 
 of sequential decision-making. 
% 
Rather than learning from a predetermined collection of input--target pairs, 
 an \gls{RL} agent generates experience through its own interaction 
 with the environment and evaluates that experience through a scalar reward signal. 
% 
Its objective is therefore not to reproduce known correct outputs, 
 but to discover a behavior that maximizes the reward accumulated over time.

This chapter introduces the \gls{RL} foundations required 
 by the contributions in~\Cref{chap:scalable-rl}.
%
\Cref{sec:rl-single-agent} presents the single-agent learning cycle, its
formalization as a \gls{MDP}, and deep Q-learning.
%
\Cref{sec:rl-multi-agent} extends this formulation to cooperative systems in
which several agents jointly influence the environment.
%
\Cref{sec:rl-scalability} then discusses why the resulting learning problem
becomes increasingly difficult as the population grows and reviews the main
families of techniques used to control this growth.
%
Finally, \Cref{sec:rl-decentralized} distinguishes decentralized execution from
decentralized training and examines approaches that reduce or remove dependence
on a central learner.


%=============================================================================
\section{Single-Agent Reinforcement Learning}
\label{sec:rl-single-agent}
\label{sec:rl-framework}
%=============================================================================

In the single-agent setting, 
 learning proceeds through a closed feedback loop
 between an \emph{agent} and an \emph{environment}~\cite{Sutton1998}.
%
As shown in~\Cref{fig:rl-loop}, 
 at discrete time step $t$, the agent observes the current state $s_t$, 
 selects an action $a_t$, and receives a scalar reward $r_{t+1}$ after 
 the environment moves to state $s_{t+1}$.
%
The new state becomes the input to the next decision, 
 and the cycle continues until a terminal condition is reached or for an indefinite horizon.
%
The sequence

\begin{equation}
  \tau = (s_0,a_0,r_1,s_1,a_1,r_2,\ldots)
  \label{eq:rl-trajectory}
\end{equation}

is referred to as a trajectory.
%
Because the trajectory depends on the actions selected by the agent, 
 the data used for learning are not independent of the learner's behavior.
%
This property distinguishes \gls{RL} from supervised learning, 
 where the training set is normally collected before optimization 
 and provides an explicit target for each input. 
% 
It also distinguishes \gls{RL} from unsupervised learning: 
 although neither setting supplies action labels, 
 \gls{RL} includes an evaluative signal that assigns value to the consequences of behavior.

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.7\textwidth]{figures/ch06/rl-cycle.drawio.pdf}
  \caption{The agent--environment interaction cycle in reinforcement learning.}
  \label{fig:rl-loop}
\end{figure}

The standard mathematical model for this interaction is a \glsfull{MDP}~\cite{szepesvari1996generalized},
 defined by the tuple

\begin{equation}
  \mathcal{M} = (\mathcal{S},\mathcal{A},P,R,\gamma),
  \label{eq:mdp-tuple}
\end{equation}

where $\mathcal{S}$ and $\mathcal{A}$ are the state and action spaces,
$P(s'\mid s,a)$ is the probability of reaching state $s'$ after action $a$ is
performed in state $s$, $R(s,a,s')$ specifies the corresponding reward, and
$\gamma \in [0,1)$ is a discount factor.
%
The Markov property requires the current state to contain all information needed
to determine the distribution of the next state and reward: conditioned on
$s_t$ and $a_t$, earlier elements of the trajectory provide no additional
information about $s_{t+1}$.

The agent selects actions according to a policy
$\pi(a\mid s)$, which assigns a probability to each action available in a given
state.
%
Its objective is to maximize the expected discounted return

\begin{equation}
  G_t = \sum_{k=0}^{\infty}\gamma^k r_{t+k+1}.
  \label{eq:discounted-return}
\end{equation}

Discounting gives greater weight to rewards obtained in the near future and
ensures that the return remains bounded in continuing tasks with bounded rewards.
%
The state--action value function associated with policy $\pi$ is

\begin{equation}
  Q^\pi(s,a) = \mathbb{E}_\pi\!\left[G_t
    \mid s_t=s,\,a_t=a\right].
  \label{eq:q-value}
\end{equation}

It measures the expected return after selecting $a$ in $s$ and following $\pi$
thereafter. The optimal action-value function $Q^*(s,a)=\max_\pi Q^\pi(s,a)$
satisfies the Bellman optimality equation

\begin{equation}
  Q^*(s,a) =
  \mathbb{E}\!\left[
    r_{t+1} + \gamma\max_{a'\in\mathcal{A}}Q^*(s_{t+1},a')
    \mid s_t=s,\,a_t=a
  \right].
  \label{eq:bellman}
\end{equation}

An optimal deterministic policy can therefore be obtained by selecting an action
that maximizes $Q^*(s,a)$ in each state.

Q-learning~\cite{watkins1992q} estimates this function directly from sampled transitions, without
requiring an explicit model of $P$ or $R$.
%
In its tabular form, the estimate is updated as

\begin{equation}
  Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha
  \left[
    r_{t+1} + \gamma\max_{a'}Q(s_{t+1},a') - Q(s_t,a_t)
  \right],
  \label{eq:q-learning-update}
\end{equation}

where $\alpha$ is the learning rate and the expression in brackets is the
temporal-difference error.
%
Tabular storage becomes impractical when $\mathcal{S}$ is large or continuous.
Deep Q-learning~\cite{mnih2015humanlevel} addresses this limitation by replacing the table with a neural
network $Q(s,a;\theta)$ parameterized by $\theta$.
%
The network is trained from transitions sampled from a replay buffer
$\mathcal{D}$ by minimizing

\begin{equation}
  \mathcal{L}(\theta) =
  \mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}
  \left[
    \left(y-Q(s,a;\theta)\right)^2
  \right],
  \qquad
  y = r + \gamma\max_{a'}Q(s',a';\theta^-),
  \label{eq:dql-loss}
\end{equation}

where $Q(s,a;\theta)$ is the online estimate and $Q(s',a';\theta^-)$ is a
target network whose parameters are updated less frequently.
%
Experience replay reduces the temporal correlation among consecutive samples,
while the target network prevents both sides of the update from changing at
every optimization step. Together, these mechanisms improve the stability of
neural value estimation.

Two difficulties remain even in this basic setting.
%
First, rewards may be delayed, so the learner must attribute later outcomes to
the earlier actions that contributed to them. This is the temporal credit
assignment problem.
%
Second, the agent must balance \emph{exploitation} of actions currently believed
to be effective with \emph{exploration} of alternatives whose consequences are
still uncertain.
%
Both difficulties carry over to the multi-agent case, where they are compounded
by interaction among several simultaneously acting learners.

\section{Multi-Agent Reinforcement Learning}
\label{sec:rl-multi-agent}
%=============================================================================

\gls{MARL} extends the interaction cycle to environments whose evolution depends
on the simultaneous decisions of multiple agents~\cite{DBLP:journals/smca/BusonuiBDS08}.
%
Depending on how rewards are related, these interactions may be competitive,
cooperative, or mixed.
%
In competitive problems, agents pursue opposing objectives; in mixed settings,
their incentives overlap only partially; and in fully cooperative problems, all
agents optimize a common objective.
%
The remainder of this chapter focuses on the cooperative case, which most closely
matches collective systems whose components must coordinate toward a shared goal.

A cooperative, partially observable multi-agent problem can be represented as a
decentralized partially observable Markov decision process~\cite{Oliehoek2016}:

\begin{equation}
  \mathcal{M}_{\mathrm{dec}} =
  (\mathcal{I},\mathcal{S},\{\mathcal{A}_i\}_{i\in\mathcal{I}},P,R,
   \{\mathcal{O}_i\}_{i\in\mathcal{I}},O,\gamma),
  \label{eq:decpomdp-tuple}
\end{equation}

where $\mathcal{I}=\{1,\ldots,N\}$ is the set of agents,
$\mathcal{A}_i$ and $\mathcal{O}_i$ are the action and observation spaces of
agent $i$, and $O$ is the observation model.
%
At time $t$, each agent receives a local observation $o_i^t$, chooses an action
$a_i^t$ according to its policy $\pi_i$, and contributes to the joint action
$\mathbf{a}_t=(a_1^t,\ldots,a_N^t)$.
%
The transition model $P(s_{t+1}\mid s_t,\mathbf{a}_t)$ depends on this joint
action, while the team reward $R(s_t,\mathbf{a}_t,s_{t+1})$ evaluates its
collective consequence.
%
Because an observation need not uniquely identify the global state, a policy may
condition its decision on an action--observation history rather than only on the
current observation.

When interactions are local, the communication or sensing relations at time $t$
can be represented by a graph

\begin{equation}
  G_t=(\mathcal{I},\mathcal{E}_t), \qquad
  \mathcal{E}_t=\{(i,j)\mid j\in\mathcal{N}_t(i)\},
  \label{eq:swarmdp-graph}
\end{equation}

where $\mathcal{N}_t(i)$ is the neighborhood of agent $i$.
%
The local observations, policies, and environment transition jointly define the
collective evolution

\begin{equation}
  \mathcal{S}
  \xrightarrow{O}
  \mathcal{O}_1\times\cdots\times\mathcal{O}_N
  \xrightarrow{\boldsymbol{\pi}}
  \mathcal{A}_1\times\cdots\times\mathcal{A}_N
  \xrightarrow{P}
  \mathcal{S},
  \label{eq:swarmdp-cycle}
\end{equation}

with joint policy $\boldsymbol{\pi}=(\pi_1,\ldots,\pi_N)$.
%
For a finite horizon $H$, the cooperative objective is

\begin{equation}
  \boldsymbol{\pi}^* =
  \arg\max_{\boldsymbol{\pi}}
  \mathbb{E}_{\boldsymbol{\pi}}
  \left[\sum_{t=0}^{H-1}\gamma^t r_{t+1}\right].
  \label{eq:swarmdp-objective}
\end{equation}

This objective resembles its single-agent counterpart, but the learning problem
is qualitatively different.
%
From the viewpoint of agent $i$, the transition dynamics observed during training
change whenever another agent changes its policy. Consequently, treating other
learners as part of the environment violates the stationarity assumption on which
standard single-agent methods rely.
%
Partial observability further prevents an agent from directly determining why a
joint action succeeded or failed.
%
Finally, a shared team reward does not identify the contribution of each agent,
creating a multi-agent credit assignment problem in addition to the temporal one.

Independent Q-learning applies a separate Q-learning process to each agent and
treats all other agents as part of the environment~\cite{tan1993multiagent}.
For agent $i$, the corresponding local estimate can be written as

\begin{equation}
  Q_i^{\boldsymbol{\pi}}(h_i^t,a_i^t) =
  \mathbb{E}_{\boldsymbol{\pi}}\!\left[
    \sum_{k=t}^{H-1}\gamma^{k-t}r_{k+1}
    \mid h_i^t,a_i^t
  \right],
  \label{eq:per-agent-q}
\end{equation}

where $h_i^t$ is the local action--observation history.
%
This formulation is simple and requires neither a joint value function nor global
information. However, it does not explicitly account for changes in the other
policies and offers no direct mechanism for assigning a team reward to individual
decisions.
%
More structured approaches address these limitations, but their computational
and communication requirements become increasingly important as $N$ grows.

\section{Scalability in MARL}
\label{sec:rl-scalability}
%=============================================================================

Scaling \gls{MARL} is not a single problem, 
 but the combination of several forms of growth.
%
If every agent has $|\mathcal{A}|$ actions, the joint action space contains
$|\mathcal{A}|^N$ alternatives. A centralized action-value function must therefore
represent and compare a number of joint decisions that grows exponentially with
the population.
%
Concatenating all observations also produces inputs whose size grows with $N$ and
ties the learned network to a fixed ordering and population size.
%
At the same time, the number of interactions that may need to be represented,
the variance of policy-gradient estimates, and the amount of experience required
to encounter coordinated behavior can all increase with the number of agents~\cite{DBLP:conf/nips/LoweWTHAM17}.

Several complementary design strategies address different parts of this problem.
%
\emph{Parameter sharing} uses the same policy parameters for homogeneous agents.
This reduces the number of learned parameters from one model per agent to a
single shared model and allows experience collected by different agents to update
the same policy.
%
It does not, by itself, solve the coordination problem: agents may still require
different actions because their observations, histories, or positions differ.

\emph{Value decomposition} avoids representing an unconstrained joint
action-value function.
%
Value-Decomposition Networks express the team value as the sum of individual
utilities~\cite{DBLP:conf/aaai/SunehagLGCZJLSL18}, while QMIX replaces additivity with a monotonic
mixing function conditioned on global information~\cite{DBLP:conf/icml/RashidSWFFW18}.
%
The monotonicity constraint ensures that maximizing each local utility also
maximizes the joint value, thereby permitting decentralized action selection.
%
These methods improve tractability and multi-agent credit assignment, but the
mixing model is trained centrally and the factorization constrains which joint
value functions can be represented.

\emph{Mean-field methods} replace the explicit influence of many agents with a
summary of their aggregate behavior~\cite{DBLP:conf/icml/YangLLZZWY18}.
%
For example, an agent may condition its value estimate on the empirical
distribution or mean action of its neighbors rather than on every neighboring
action separately.
%
This changes an interaction with a growing collection of agents into one between
an individual and an aggregate. The approximation is most appropriate when the
population is sufficiently large and individual interactions are exchangeable;
it can lose relevant structure when a small number of heterogeneous neighbors has
a disproportionate effect.

\emph{Locality-aware representations} exploit the fact that many collective
systems are governed primarily by nearby interactions.
%
When the interaction graph $G_t$ is available, a \gls{GNN} can construct each
agent's representation by aggregating messages from its neighborhood, using the
mechanism introduced in~\Cref{eq:aggregate}.
%
Because the same message and update functions are applied to every node, the
number of policy parameters does not depend directly on $N$, and permutation-
invariant aggregation avoids dependence on an arbitrary ordering of neighbors.
Graph Convolutional Reinforcement Learning provides an example of this approach
in MARL~\cite{DBLP:conf/iclr/JiangDHL20}.
%
A graph-based policy can therefore be evaluated on populations and topologies of
different sizes without changing its architecture. This property makes zero-shot
transfer across population sizes possible, although it does not guarantee that a
policy trained at one scale will remain effective at another: changes in density,
connectivity, or collective dynamics may still induce a substantial distribution
shift.

\section{Decentralized MARL}
\label{sec:rl-decentralized}
%=============================================================================

Decentralization in MARL has two distinct meanings.
%
\emph{Decentralized execution} requires each agent to select actions from locally
available information after training. \emph{Decentralized training} additionally
requires policy optimization to proceed without a central learner that collects
the global state, trajectories, or model updates.
%
Conflating these requirements obscures an important distinction: a policy may be
decentralized at deployment while having been learned through a fully centralized
procedure.

The dominant compromise is \glsfull{CTDE}.
%
During training, a centralized critic or value-mixing network may use the global
state and the actions or observations of all agents. At execution time, each
agent acts from its local observation or history.
%
Multi-Agent Deep Deterministic Policy Gradient exemplifies centralized critics,
while QMIX exemplifies centralized value factorization~\cite{DBLP:conf/nips/LoweWTHAM17,DBLP:conf/icml/RashidSWFFW18}.
%
Access to joint information during training reduces the apparent non-stationarity
of the learning target and can support more informative credit assignment.
However, it assumes that experience can be collected centrally and that the
training infrastructure can process joint information, assumptions that become
difficult to satisfy in large, open, or geographically distributed systems.

At the opposite extreme, independent learners optimize their policies using only
local trajectories and rewards. This is decentralized in both training and
execution and requires no inter-agent communication for learning.
%
Its simplicity and weak infrastructure assumptions come at the cost of treating
the changing behavior of other agents as unmodeled environment dynamics.
Consequently, independently learned policies may be unstable or fail to discover
behaviors that require coordinated exploration.

Between these extremes, networked approaches retain decentralized training while
allowing neighboring agents to exchange learning information.
%
In fully decentralized MARL with networked agents, each agent performs local
actor--critic updates and combines selected parameters or value estimates with
those received from its neighbors through consensus~\cite{zhang2018fully}.
%
Repeated local exchanges allow information to propagate without a parameter
server. Their effectiveness depends on the communication graph: sparse,
intermittent, or poorly connected topologies slow consensus and may leave
different portions of the collective with inconsistent estimates.
%
They also introduce a systems-level trade-off between the frequency and volume of
communication and the speed at which learning information diffuses.

Communication can concern either the learning process or the execution policy.
Parameter and gradient exchanges belong to the former category. In the latter,
agents exchange messages that become inputs to their action-selection process.
Architectures such as CommNet and Differentiable Inter-Agent Learning train the
content of these messages jointly with the policy
~\cite{DBLP:conf/nips/SukhbaatarSF16,DBLP:conf/icml/FoersterAFW16}.
%
Learned communication can improve coordination when local observations omit
information held by other agents, but it does not automatically imply
decentralized training: differentiable communication channels are commonly
optimized with joint trajectories and centralized backpropagation.

The relevant choice is therefore not whether a method is simply centralized or
decentralized, but which information is shared, with whom, and at what stage.
%
Centralized training can exploit joint information but creates a coordination
and infrastructure bottleneck. Independent learning removes that bottleneck but
weakens the learning signal available to each agent. Networked training occupies
the middle ground, using local communication to improve collective learning while
preserving the absence of a central coordinator.
%
This last setting provides the conceptual basis for the decentralized and
scalable reinforcement-learning methods developed in Chapter~8.
