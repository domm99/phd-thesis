\chapter{Self-Organizing Federated Learning}
\label{chap:selforg-fl}
\minitoc
%----------------------------------------------------------------------------------------

The chapters on machine learning (\Cref{chap:ml})
 and federated learning (\Cref{chap:federated-learning})
 established the landscape of distributed model training and identified two
 compounding challenges that arise in \gls{CAS} deployments.
%
First, data are spatially heterogeneous: devices in the same geographic region
 tend to observe similar distributions,
 while devices in different regions observe distributions that may be
 incompatible with a single shared model.
%
Second, \gls{FL} systems typically require a central server to coordinate training,
 an assumption that breaks down in large-scale networks of autonomous
 devices where no single node has global visibility.

This chapter presents the research contributions that address these two challenges jointly.
%
The core idea is to combine the \gls{SCR} pattern from aggregate computing
 (\Cref{chap:macroprogramming}) with a clustered \gls{FL} training loop,
 obtaining a fully decentralized system that self-organizes into
 spatially coherent training federations.
%
\Cref{sec:selforgfl-motivation} motivates the approach and positions it
 with respect to the background covered in earlier chapters.
%
\Cref{sec:selforgfl-formalization} provides a unified formal model of
 the system and the learning problem.
%
\Cref{sec:selforgfl-approach} introduces the unified field-based coordination framework common to all three contributions.
%
\Cref{sec:fbfl,sec:psfl,sec:sparseful} present each contribution in detail---\gls{FBFL}, \gls{PSFL}, and \textsc{SParSeFuL} respectively---each with its specialization of the framework, experimental setup, and discussion of results.
%
\Cref{sec:selforgfl-benchmarking} describes \textsc{ProFed}, a benchmarking framework developed alongside the algorithms to enable reproducible evaluation of proximity-based \gls{FL} methods.
%
\Cref{sec:selforgfl-related} situates the contributions in the
 broader literature on clustered and decentralized \gls{FL}.
%
Finally, \Cref{sec:selforgfl-future} outlines two ongoing extensions
 that address mobility-induced distribution shift and uncertainty-driven
 cluster discovery.


%=============================================================================
\section{Motivation}
\label{sec:selforgfl-motivation}
%=============================================================================

Standard \gls{FL} algorithms such as \gls{FedAvg}~\cite{DBLP:conf/aistats/McMahanMRHA17}
 are designed under the assumption that a global model is both
 attainable and desirable.
%
\sidenote{ref here}
In practice, this assumption frequently fails.
%
When data distributions vary significantly across clients 
 (a condition commonly referred to as statistical heterogeneity or non-\gls{IID} data) 
 training a single global model introduces a bias toward the majority distribution and degrades
 performance for underrepresented clients.

The heterogeneity problem is especially acute in spatially distributed
 \gls{CAS}:
 devices co-located in the same urban district, sensor field, or
 industrial site observe correlated local phenomena,
 while devices in distant regions observe systematically different ones~\cite{esterle2022deep}.
%
As discussed in \Cref{sec:fl-heterogeneity},
 this spatial structure implies that the globally optimal partition
 \sidenote{questo non mi fa impazzire}
 of clients into cooperative groups largely follows geography.
%
\sidenote{magari citarne altri}
Existing clustered \gls{FL} algorithms (e.g., IFCA~\cite{DBLP:journals/tit/GhoshCYR22})
 assume a central server that knows the number of clusters in advance
 and assigns clients to them through server-side computation.
%
Neither assumption holds in large-scale \gls{CAS}:
 the number of natural data clusters is not known a priori,
 and the devices themselves may not have access to a reliable
 coordination infrastructure.

The approach developed in this chapter frames the clustering problem
 as a self-organization problem amenable to field-based coordination.
%
Rather than relying on a server to assign devices to federations,
 each device participates in a distributed leader election
 that partitions the network into spatially compact regions.
%
Within each region a federated training round proceeds independently,
 aggregating only models from devices whose data are likely to be
 compatible.
%
The coordination layer is implemented entirely through the
 aggregate computing primitives described in \Cref{chap:macroprogramming},
 which provide provable convergence guarantees
 and tolerate node failures and dynamic network topologies.

This design answers a concrete gap identified in
 \Cref{sec:fl-selforg-preview}:
 the need for a \gls{FL} system that (i) does not require a
 central server, (ii) discovers the number and composition of
 training clusters autonomously, and (iii) exploits the spatial
 structure of data distributions to improve model quality.

%\subsection{Network Model}

Consider a distributed network comprising a set of devices, 
 denoted as $\mathcal{V}$.
%
This network can be modelled as a graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$,
 with nodes representing devices and edges symbolizing direct communication links. 
%
The neighbors of a device $d$, with which $d$ can exchange messages, 
 are denoted by $\mathcal{N}_d = \{d' \in \mathcal{V} \mid (d, d') \in \mathcal{E}\}$.

\begin{assumption}[Network Connectivity]\label{assumption:network-connectivity}
The communication graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ is connected, 
 ensuring information can eventually propagate between any two devices.
\end{assumption}
%
\begin{assumption}[Reliable Message Delivery]\label{assumption:reliable-message-delivery}
Communication between neighboring devices $d, d' \in \mathcal{V}$ where $(d, d') \in \mathcal{E}$ is reliable, 
 though messages may experience bounded delays.
\end{assumption}

The devices in $\mathcal{V}$ are deployed across a spatial area
 $A = \{a_1, a_2, \ldots, a_k\}$ divided into $k$ distinct contiguous subregions.
%
Each subregion $a_j$ is characterized by a unique data distribution $P_j$
 over the input-output space $\mathbb{R}^m \times \mathcal{Y}$,
 reflecting the localized phenomena observed in that portion of the environment.
%
The number of devices far exceeds the number of subregions ($n = |\mathcal{V}| \gg k$),
 so that each subregion contains multiple devices.
%
Each device $d$ resides in some subregion $a_j$
 and its local dataset is drawn from the corresponding distribution $P_j$:
 devices within the same subregion share a common data distribution,
 while devices in different subregions may observe statistically distinct data.
%
\begin{assumption}[Spatial-Data Correlation]\label{assumption:spatial-data-correlation}
Devices within the same subregion $a_j \in A$ exhibit similar data distributions:
 for any $d, d' \in \mathcal{V}$ residing in the same subregion,
 the statistical distance between their local distributions satisfies
 $D(\mathbb{P}_d, \mathbb{P}_{d'}) < \epsilon$ for some threshold $\epsilon > 0$,
 while devices in distinct subregions may have significantly different distributions.
\end{assumption}

Each device $d \in \mathcal{V}$ possesses a local dataset $\mathcal{D}_d = \{(x_i, y_i)\}_{i=1}^{n_d}$,
 where $x_i \in \mathbb{R}^m$ represents the input features, $y_i \in \mathcal{Y}$ the corresponding labels,
 and $n_d = |\mathcal{D}_d|$ the number of samples on device $d$.
%
The local data distribution $\mathbb{P}_d(x,y)$ coincides with $P_j$ for the subregion $a_j$
 in which $d$ resides,
 and may therefore differ across devices in different subregions
 ($\mathbb{P}_d \neq \mathbb{P}_{d'}$ for $d, d'$ in distinct subregions). 

The dataset on device $d$ is used to train a local model, 
 characterized by a weights vector $\mathbf{w}_d \in \mathbb{R}^p$, 
 where $p$ represents the total number of parameters in the neural network architecture. 
%
\begin{assumption}[Shared Model Initialization]\label{assumption:shared-model-initialization}
All devices $d \in \mathcal{V}$ start with the same initial model $\mathbf{w}_d^{(0)} = \mathbf{w}^{(0)}$, 
 ensuring a common starting point for the learning process.
%
This may be a pre-trained model or a randomly initialized model shared via a global elected leader.
\end{assumption}

\begin{assumption}[Synchronized Federated Learning Rounds]\label{assumption:synchronized-fl-rounds}
There exists a global synchronization mechanism that ensures all devices 
 progress through federated learning rounds in discrete time steps $t \in \{0, 1, 2, \ldots, \mathcal{T}\}$, 
 where devices complete local training, model sharing, and aggregation phases 
 within bounded time intervals before proceeding to round $t+1$.
\end{assumption}
%
At federated learning round $t$, 
 the local objective function $f_d: \mathbb{R}^p \rightarrow \mathbb{R}$ measures the empirical risk 
 on device $d$'s local dataset:
%
\begin{equation}
f_d(\mathbf{w}_d^{(t)}) = \frac{1}{n_d} \sum_{i=1}^{n_d} \ell(h(\mathbf{w}_d^{(t)}; x_i), y_i),
\end{equation}
%
where $h(\mathbf{w}_d^{(t)}; x_i)$ denotes the model's prediction for input $x_i$ given parameters $\mathbf{w}_d^{(t)}$, 
 and $\ell(\cdot, \cdot)$ represents the loss function (e.g. cross-entropy for classification tasks).

In traditional federated learning, 
 the global objective seeks to minimize a weighted combination of all local objectives:
\begin{equation}
  f(\mathbf{w}) = \sum_{d \in \mathcal{V}} \alpha_d f_d(\mathbf{w}),
\end{equation}
%
where $\alpha_d = \frac{n_d}{|D|}$ represents the relative weight of device $d$'s data contribution, 
 with $|D| = \sum_{d \in \mathcal{V}} n_d$ being the total number of samples across all devices.

Rather than optimizing a single global model,
 the approach pursued in this chapter is to partition $\mathcal{V}$ into groups of compatible devices
 and train a specialized model for each group.
%
Formally, assume the devices admit a latent partition into $k$ clusters
 $C_1, \ldots, C_k$, with $C_q \cap C_r = \emptyset$ for $q \neq r$
 and $\bigcup_{q=1}^k C_q = \mathcal{V}$.
%
This partition reflects the underlying spatial and distributional structure of the data,
 but is \emph{not known} to the devices at learning time.

The learning problem can then be framed as finding a mapping $\mathcal{M}$
 from the set of devices to a collection of \emph{federations}:
\begin{equation}
  \mathcal{M} : \mathcal{V} \;\rightarrow\; \mathcal{F} \subseteq \mathcal{P}(\mathcal{V}),
\end{equation}
where $\mathcal{P}(\mathcal{V})$ denotes the power set of $\mathcal{V}$
 and $\mathcal{F} = \{F_1, \ldots, F_f\}$ is the set of discovered federations.
%
Each federation $F_q \subseteq \mathcal{V}$ runs an independent federated learning process,
 training a specialized model $\mathbf{w}_q$ by minimizing a weighted combination
 of the local objectives of its members:
\begin{equation}
  f_q(\mathbf{w}_q) = \sum_{d \in F_q} \alpha_{d,q} \, f_d(\mathbf{w}_q),
  \label{eq:cluster-objective}
\end{equation}
where $\alpha_{d,q} = \frac{n_d}{\sum_{d' \in F_q} n_{d'}}$ is the normalized data weight
 of device $d$ within federation $F_q$.
%
The overall goal is that each discovered federation $F_q$ recovers the corresponding true cluster
 as closely as possible;
 following, this is formalized as minimizing the \emph{misclassification rate}:
\begin{equation}
  \min_{\mathcal{M}} \;\frac{1}{|\mathcal{V}|} \min_{\pi \in \Pi_k}
    \sum_{q=1}^{f} \bigl|F_q \mathbin{\triangle} C_{\pi(q)}\bigr|,
  \label{eq:misclassification}
\end{equation}
where $\Pi_k$ is the set of all permutations over $\{1, \ldots, k\}$
 and $\triangle$ denotes the symmetric difference between sets.
%
The concrete mechanisms through which the federations $\mathcal{F}$ are discovered
 and maintained are the subject of the contributions described in the following sections.

\section{Field-Based Federated Learning}
\label{sec:selforgfl-approach}
%=============================================================================

As discussed in~\Cref{sec:selforgfl-motivation}, 
 the approach developed in this chapter frames the custering problem as a self-organization problem 
 amenable to field-based coordination.
%
The main objective of this line of work has therefore been to map the key
concepts and operations of \gls{FL} onto the abstractions provided by aggregate
computing.
%
Under this mapping, a federation corresponds to a self-organizing region, its
aggregator corresponds to the region leader, and the exchange of models between
devices and aggregators is expressed through collective information flows.
%
This makes it possible to describe the entire learning process as a distributed
aggregate program, without relying on a distinguished server or requiring the
number and composition of the federations to be known in advance.

The coordination structure is obtained through the
Self-organizing Coordination Regions (\gls{SCR}) pattern introduced in
Chapter~3.
%
The pattern combines three aggregate computing building blocks.
%
The sparse-choice operator \texttt{S} performs a distributed multi-leader
election, selecting leaders that are sufficiently separated according to a
generic device-to-device distance function \(d(\cdot,\cdot)\) and an influence
threshold \(\sigma\).
%
The elected leaders induce a Voronoi-like partition of the network, with each
device associated with its closest leader according to the path metric induced
by \(d\).

More precisely, the coordination layer constructs a gradient field
\(\Phi : \mathcal{V} \rightarrow \mathbb{R}_{\geq 0}\) that associates each
device with its cumulative distance from the closest federation leader.
%
At round \(t\), the field is defined recursively as
%
\begin{equation}
  \Phi^{(t)}(d_i) =
  \begin{cases}
    0,
      & \text{if } d_i \in \mathcal{L}^{(t)}, \\[2mm]
    \displaystyle
    \min_{d_j \in \mathcal{N}_i}
    \left\{
      \Phi^{(t)}(d_j) + d(d_i,d_j)
    \right\},
      & \text{otherwise}.
  \end{cases}
  \label{eq:generic-federation-gradient}
\end{equation}
%
Consequently, \(\Phi^{(t)}(d_i)\) represents the minimum cumulative distance
between device \(d_i\) and any elected leader, computed over the paths in the
communication graph.
%
Together with a deterministic tie-breaking rule, this field determines both
the leader associated with each device and the gradient paths connecting the
device to that leader.

Within each resulting region, the collect-cast operator \texttt{C} exploits
these paths to establish an upstream information flow from the devices to the
leader, possibly through intermediate devices.
%
Conversely, the gradient-cast operator \texttt{G} establishes the corresponding
downstream flow from the leader to the region members.
%
In the \gls{FL} setting, these operations support the three main coordination
phases of the learning process: federation formation, collection of the locally
trained models, and dissemination of the aggregated regional models.

The resulting learning loop is summarized in
\Cref{algo:fbfl-general}.
%
At each round \(t\), the distributed leader election algorithm
\(\mathcal{DL}(d,\sigma)\) determines a set of leaders
\(\mathcal{L}^{(t)}\) and induces the corresponding partition
\(\{\mathcal{R}_l^{(t)}\}_{l \in \mathcal{L}^{(t)}}\).
%
Each device then trains its current model on its local dataset and sends the
resulting update to its region leader through the paths established by
\texttt{C}.
%
The leader aggregates the collected updates into a region-specific model and
disseminates it to the region members through \texttt{G}.
%
The same procedure is executed concurrently in every region, resulting in
multiple federated learning processes coordinated exclusively through local
interactions.
%
Although \Cref{algo:fbfl-general} leaves the aggregation operator unspecified,
standard aggregation rules such as \gls{FedAvg} can be employed without
altering the coordination structure.

\begin{algorithm}[t]
  \caption{General Field-Based Federated Learning round.}
  \label{algo:fbfl-general}
  \begin{algorithmic}[1]
    \Require Communication graph
             \(\mathcal{G}=(\mathcal{V},\mathcal{E})\),
             distance function \(d(\cdot,\cdot)\),
             influence threshold \(\sigma\),
             local epochs \(E\),
             total rounds \(\mathcal{T}\),
             initial model \(\mathbf{w}^{(0)}\)

    \For{\(t = 0\) \textbf{to} \(\mathcal{T}-1\)}
      \State
        \(\mathcal{L}^{(t)} \gets \mathcal{DL}(d,\sigma)\)
        \Comment{distributed leader election via \texttt{S}}

      \State
        induce partition
        \(\{\mathcal{R}_l^{(t)}\}_{l \in \mathcal{L}^{(t)}}\)
        via gradient field \texttt{G}

      \ForAll{\(d_i \in \mathcal{V}\)}
        \Comment{in parallel}

        \State
          \(\tilde{\mathbf{w}}_i^{(t)}
          \gets
          \mathrm{LocalTrain}
          (\mathbf{w}_i^{(t)},\mathcal{D}_i,E)\)

        \State
          route \(\tilde{\mathbf{w}}_i^{(t)}\) to leader
          \(d_{\mathcal{L}}^{(t)}\) via \texttt{C}
          along the gradient path
      \EndFor

      \ForAll{\(l \in \mathcal{L}^{(t)}\)}
        \Comment{in parallel}

        \State
          \(\mathbf{w}_l^{(t+1)}
          \gets
          \mathrm{Aggregate}
          \left(
            \{\tilde{\mathbf{w}}_d^{(t)}\}_{d \in \mathcal{R}_l^{(t)}}
          \right)\)
          \Comment{any aggregation rule, e.g., \gls{FedAvg}}

        \State
          broadcast \(\mathbf{w}_l^{(t+1)}\) to all
          \(d \in \mathcal{R}_l^{(t)}\) via \texttt{G}
      \EndFor

      \ForAll{\(d_i \in \mathcal{V}\)}
        \State
          \(\mathbf{w}_i^{(t+1)}
          \gets
          \mathbf{w}_{d_{\mathcal{L}}^{(t)}}^{(t+1)}\)
      \EndFor
    \EndFor
  \end{algorithmic}
\end{algorithm}

The distance function \(d(\cdot,\cdot)\) is the main specialization point of
the framework.
%
Since sparse choice operates over the path metric induced by \(d\), changing
this function affects both the placement of the leaders and the boundaries of
the resulting regions, while leaving the remaining learning loop unchanged.
%
When \(d\) represents the physical distance between neighboring devices, the
framework produces spatially compact federations and is therefore suitable for
scenarios in which spatial proximity is a reliable proxy for similarity between
local data distributions.
%
Alternatively, \(d\) can be defined using information derived from the models
and their performance on local data, allowing federation formation to account
for learning compatibility in addition to network proximity.
%
The approaches presented in the following sections instantiate this common
framework using different distance functions and, consequently, different
notions of which devices should participate in the same federation.

As with other aggregate computing processes, the regions and their associated
information flows converge when the network topology and the values involved in
the distance function remain stable for sufficiently long.
%
Changes in topology, device state, or model similarity may temporarily alter
leader selection and federation membership; the repeated evaluation of the
\gls{SCR} pattern then drives the system toward a new stable organization.
%
Federation formation is therefore not a preliminary centralized clustering
step, but an integral and continuously adaptive component of the distributed
learning process.
%
Unlike clustered \gls{FL} approaches such as IFCA, the proposed framework
does not require the number of federations to be specified in advance.
%
Instead, both their number and composition emerge from local interactions among
devices according to the selected distance function and influence threshold.
%
This property is particularly important in \glspl{CAS}, where the underlying
number of data clusters may be difficult to estimate and may change as the
system evolves.
%
As shown in the following sections, incorrectly specifying this number can force
devices with incompatible data distributions into the same federation or
unnecessarily separate compatible devices, ultimately degrading learning
performance.

\section{Field-Based Federated Learning with Spatial Proximity}
\label{sec:fbfl}
%=============================================================================

This section presents the first instantiation of the framework 
 introduced in \Cref{sec:selforgfl-approach}, 
 namely \glsentryfull{FBFL}~\cite{DBLP:journals/lmcs/DominiAEV26}.
%
In this approach, 
 federation formation is driven exclusively by the physical distance between devices.
%
Consequently, 
 \gls{FBFL} is intended for scenarios in which spatial proximity provides a meaningful proxy 
 for similarity between local data distributions.


\subsection{Algorithm Description}
\label{sec:fbfl-spatial-algorithm}

\gls{FBFL} instantiates the generic distance function \(d(\cdot,\cdot)\) 
 with the Euclidean distance between the physical positions of neighboring devices.
%
Let \(\mathbf{p}_i\) and \(\mathbf{p}_j\) denote the positions 
 of devices \(d_i\) and \(d_j\), respectively.
%
Their local distance is defined as
%
\begin{equation}
  d_{\mathrm{E}}(d_i,d_j)
  =
  \left\lVert
    \mathbf{p}_i-\mathbf{p}_j
  \right\rVert_2.
  \label{eq:fbfl-euclidean-distance}
\end{equation}
%
The distributed leader election is therefore instantiated as
 \(\mathcal{DL}(d_{\mathrm{E}},R)\), where the generic influence threshold
 \(\sigma\) introduced in the previous section becomes a physical radius \(R\).
%
The resulting federations form a Voronoi-like spatial partition of the network:
 each device is associated with the closest reachable leader according to the
 path metric induced by \(d_{\mathrm{E}}\).
%
Hence, 
 federation formation is purely spatial and does not depend on either the
 local datasets or the models trained by the devices.

\Cref{lst:fbfl-scafi} shows the complete ScaFi~\cite{DBLP:journals/softx/CasadeiVAP22}
 implementation of the learning process.

\begin{lstlisting}[
  language=scafi,
  caption={FBFL implementation using aggregate computing primitives.},
  label={lst:fbfl-scafi}
]
val leaders = S(radius, nbrRange)
def syncCondition: Boolean = ???
rep(initModel()) { localModel =>
  if (syncCondition) { localModel.trainLocally() }
  val potential = gradient(leaders)
  val collectedModels = C(potential, _ ++ _, Set(localModel), Set.empty)
  val aggregatedModel = if (leaders) fedAvg(collectedModels) else emptyModel
  val regionalModel = G(leaders, aggregatedModel, identity) 
  mux(syncCondition) { regionalModel } { localModel }
}
\end{lstlisting}

The specialization of the general framework is concentrated in the first line:
 \lstinline[language=scafi]|S(radius, nbrRange)| elects spatially separated
 leaders using the Euclidean distance exposed by \lstinline[language=scafi]|nbrRange|.
%
The remainder implements the learning loop described in \Cref{algo:fbfl-general}.
%
The \lstinline[language=scafi]|rep| construct maintains the current model across rounds, 
 while \lstinline[language=scafi]|syncCondition| determines when a new federated learning round is performed.
%
Within each round, \texttt{C} collects locally trained models at the leaders,
 \lstinline[language=scafi]|fedAvg| produces the regional models, 
 and \texttt{G} disseminates them to the corresponding federation members.


\subsection{Research Questions}
\label{sec:fbfl-research-questions}

The evaluation investigates whether spatially organized federations can preserve
 the performance of centralized \gls{FL} under homogeneous data, 
 improve learning under spatially correlated heterogeneity, 
 and provide resilience against aggregator failures.
%
More specifically, 
 it addresses the following research questions:

\begin{enumerate}[
  label=\textbf{RQ\arabic*:},
  ref=RQ\arabic*,
  leftmargin=*
]
  \item
  How does Field-Based Federated Learning perform compared with centralized
  \gls{FL} under \gls{IID} data?
  \label{rq:fbfl-iid}

  \item
  Can accuracy be improved by introducing personalized learning regions in
  which devices are grouped according to the similar experiences commonly
  observed at spatially close locations?
  More precisely, what is the effect of this organization under heterogeneous
  and non-\gls{IID} data distributions?
  \label{rq:fbfl-non-iid}

  \item
  What is the effect of using field-based coordination to construct a
  self-organizing hierarchical architecture in terms of resilience,
  adaptability, and fault tolerance?
  \label{rq:fbfl-resilience}
\end{enumerate}

Three centralized \gls{FL} algorithms were employed as baselines:
 \gls{FedAvg}~\cite{DBLP:conf/aistats/McMahanMRHA17},
 FedProx~\cite{DBLP:conf/mlsys/LiSZSTS20}, 
 and Scaffold~\cite{DBLP:conf/icml/KarimireddyKMRS20}.
%
First, 
 \gls{FBFL} was compared with \gls{FedAvg} under a homogeneous data distribution 
 to assess whether field-based coordination introduces a loss in learning performance 
 when no data heterogeneity is present.
%
The comparison was then extended to all three baselines under heterogeneous data distributions.

Two synthetic partitioning strategies were used to generate non-\gls{IID} data:

\begin{enumerate}
  \item
  \emph{Dirichlet partitioning}, in which each region receives samples from  most classes,
   but with highly imbalanced class proportions; and
  \item
  \emph{hard partitioning}, in which each region contains only a strict subset
  of the available labels, producing a more challenging learning scenario.
\end{enumerate}

\section{Space-Fluid Self-Organizing Federated Learning}
\label{sec:psfl}
%=============================================================================

The purely spatial organization adopted by \gls{FBFL} is effective when physical
proximity reflects similarity between local data distributions.
%
However, physical proximity alone does not indicate whether the data observed
by nearby devices are compatible.
%
\sidenote{ Questa è da spiegare meglio }
Devices located in the same area may monitor different phenomena or interact
with the environment under different conditions, while devices with similar
experiences may not necessarily be geographically close.
%
Proximity-Aware Self-Federated Learning
(\gls{PSFL})~\cite{DBLP:journals/iot/DominiFAVE26} addresses this limitation by
replacing Euclidean distance with a data-aware measure derived from the models
trained by neighboring devices.

This change makes federation formation \emph{space-fluid}: the coordination
structure remains embedded in the communication network, but the perceived
distance between devices depends on their learning compatibility.
%
Consequently, federation boundaries can expand across devices whose models
behave similarly and contract when neighboring devices observe incompatible
data distributions.


\subsection{Algorithm Description}
\label{sec:psfl-algorithm}

\gls{PSFL} follows the general learning loop introduced in
\Cref{sec:selforgfl-approach}.
%
Its distinguishing element is the distance function used by sparse choice and
gradient propagation.
%
Instead of the Euclidean metric \(d_{\mathrm{E}}\) adopted by \gls{FBFL},
\gls{PSFL} defines a loss-based dissimilarity \(d_{\mathrm{s}}\) between the
models of neighboring devices.

After local training at round \(t\), each device \(d_i\) exchanges its locally
trained model \(\widetilde{\mathbf{w}}_i^{(t)}\) with its neighbors.
%
Device \(d_i\) evaluates the model received from \(d_j\) on its own local data,
obtaining the cross-evaluation loss
%
\begin{equation}
  L_{i,j}^{(t)}
  =
  \frac{1}{|\mathcal{D}_i|}
  \sum_{(\mathbf{x},y)\in\mathcal{D}_i}
  \ell\left(
    h\left(\widetilde{\mathbf{w}}_j^{(t)};\mathbf{x}\right),
    y
  \right).
  \label{eq:psfl-cross-evaluation-loss}
\end{equation}
%
The value \(L_{i,j}^{(t)}\) measures how well the model trained by \(d_j\)
generalizes to the data observed by \(d_i\).
%
Since this evaluation is directional, \(L_{i,j}^{(t)}\) and
\(L_{j,i}^{(t)}\) may differ.
%
The two devices therefore exchange their cross-evaluation losses and combine
them into the symmetric distance
%
\begin{equation}
  d_{\mathrm{s}}^{(t)}(d_i,d_j)
  =
  L_{i,j}^{(t)} + L_{j,i}^{(t)}.
  \label{eq:psfl-model-dissimilarity}
\end{equation}
%
A low value indicates that both models generalize well to the other device's
data and therefore suggests compatible local distributions.
%
Conversely, a high value in either direction increases the distance between the
devices.
%
This bidirectional evaluation prevents two devices from being considered
compatible merely because one of their models generalizes to the other's data.
%
Moreover, the computation does not require raw data to be exchanged: devices
share only their locally trained models and the resulting scalar losses.

The complete procedure is illustrated in
\Cref{fig:psfl-loss-similarity}.
%
After local training, neighboring devices exchange their models, evaluate the
received model on their private data, exchange the resulting losses, and compute
their symmetric distance.

\begin{figure}[t]
  \centering
  \includegraphics[
    width=0.8\textwidth
  ]{figures/ch07/sparseful/loss-dissimilarity.pdf}
  \caption{
    Loss-based similarity estimation between neighboring devices.
    After local training, the devices exchange their models and evaluate the
    received model on their own data.
    The resulting cross-evaluation losses are then exchanged and summed to
    obtain the symmetric distance \(d_{\mathrm{s}}\).
  }
  \label{fig:psfl-loss-similarity}
\end{figure}

The corresponding path metric accumulates model dissimilarity along the
communication graph.
%
As a result, federation formation accounts for both model compatibility and
topological proximity: incompatible neighbors sharply increase the accumulated
distance, while longer paths naturally accumulate the contributions of multiple
device pairs.
%
The threshold \(\sigma\) controls the maximum cumulative dissimilarity that can
be covered by one leader.
%
Smaller values produce finer partitions, whereas larger values allow
federations to span longer and potentially more heterogeneous paths.

\Cref{lst:psfl-scafi} shows the corresponding ScaFi implementation.

\begin{lstlisting}[
  language=scafi,
  caption={
    PSFL implementation using a loss-based space-fluid metric.
  },
  label={lst:psfl-scafi}
]
def proximityAwareSelfFederatedLearning(
    sigma: Double,
    initialModel: Model
): Model =
  rep(initialModel) { previousModel =>
    val localModel =
      localTraining(localDataset, previousModel)

    def metric(): Double =
      computeModelLossDissimilarity(
        localModel,
        nbr(localModel)
      )

    val leaders = S(sigma, metric)
    val region = G(leaders, metric)

    val collectedModels =
      C(
        region,
        _ ++ _,
        Set(localModel),
        Set.empty
      )

    val aggregatedModel =
      mux(leaders)(
        fedAvg(collectedModels)
      )(
        localModel
      )

    G(leaders, aggregatedModel, region)
  }
\end{lstlisting}

As in the \gls{FBFL} implementation presented in
\Cref{lst:fbfl-scafi}, the program maintains the local model through
\lstinline[language=scafi]|rep| and uses \texttt{C} and \texttt{G} for model
collection and dissemination.
%
The relevant difference lies in
\lstinline[language=scafi]|metric|, which computes
\Cref{eq:psfl-model-dissimilarity} between neighboring devices and is used by
both leader election and gradient construction.
%
Thus, the coordination structure changes as the models evolve, allowing
federation membership to adapt throughout the learning process.


\subsection{Research Questions}
\label{sec:psfl-research-questions}

The evaluation investigates whether the loss-based space-fluid metric can form
coherent federations without central coordination, improve learning under
non-\gls{IID} data, and adapt federation membership as devices move through the
system.
%
More specifically, it addresses the following research questions:

\begin{enumerate}[
  label=\textbf{RQ\arabic*:},
  ref=RQ\arabic*,
  leftmargin=*
]
  \item
  Can devices be clustered according to both topological proximity and data
  distribution similarity in a fully decentralized manner?
  \label{rq:psfl-clustering}

  \item
  Can the resulting clustering strategy improve model accuracy under
  non-\gls{IID} data distributions?
  \label{rq:psfl-accuracy}

  \item
  Can the self-organizing federation structure adapt to device mobility without
  disrupting the learning process?
  \label{rq:psfl-mobility}
\end{enumerate}


\subsection{Experimental Setup}
\label{sec:psfl-experimental-setup}

The evaluation was conducted on Extended MNIST
(EMNIST)~\cite{DBLP:journals/corr/CohenATS17} and
CIFAR-100~\cite{krizhevsky2009learning}, imported through the ProFed
benchmark~\cite{DBLP:journals/jors/DominiIALV26}.
%
For EMNIST, the handwritten-letters variant was used, containing \(124\,800\)
training samples and \(20\,800\) test samples from \(26\) classes.
%
CIFAR-100 contains \(50\,000\) training images and \(10\,000\) test images from
\(100\) classes.

Data were synthetically partitioned to produce label skew across spatial
regions.
%
The allocation followed the same region-based procedure described in
\Cref{sec:fbfl-experimental-setup}: devices assigned to the same region received
\gls{IID} data relative to one another, while devices in different regions
observed different subsets of labels.
%
Synthetic partitioning made it possible to control the degree of heterogeneity
and evaluate configurations with \(3\), \(5\), and \(9\) underlying regions.
%
Each simulation comprised \(50\) devices.

\gls{PSFL} was compared with \gls{FedAvg}, FedProx, Scaffold, and IFCA.
%
The same learning hyperparameters were used for all approaches.
%
Training lasted \(60\) global rounds, with each device performing \(2\) local
epochs per round using batches of \(64\) samples.
%
The models were optimized using Adam with a learning rate of \(0.001\) and
weight decay of \(0.0001\).
%
An MLP was employed for EMNIST, while CIFAR-100 used
MobileNet~\cite{DBLP:conf/cvpr/SandlerHZZC18}.
%
Within each \gls{PSFL} federation, models were aggregated using
\gls{FedAvg}.

The implementation combined ScaFi~\cite{DBLP:journals/softx/CasadeiVAP22}
for aggregate computing, PyTorch~\cite{paszke2017automatic} for model training,
and Alchemist~\cite{DBLP:journals/jos/PianiniMV13} for simulation.
%
The baseline algorithms were implemented directly in PyTorch.
%
The source code and execution instructions are publicly
available\footnote{\url{https://github.com/davidedomini/experiments-2025-iot-self-fl}}.

For each baseline, \(20\) simulations were performed using different random
seeds.
%
For \gls{PSFL}, \(180\) simulations explored all combinations of
\(20\) random seeds, \(3\), \(5\), and \(9\) spatial regions, and dissimilarity
thresholds \(\sigma\in\{20,40,80\}\).

In addition to the main evaluation, a mobility experiment assessed the ability
of the federation structure to adapt to changes in device position.
%
A new device, denoted by \(\bigstar\), was introduced into a stable
nine-region system and moved sequentially through all regions, remaining in each
one for \(5\) time steps.
%
The experiment lasted \(140\) time steps and was repeated \(10\) times with
different random seeds and \(\sigma=20\).

In addition to training loss, validation loss, and validation accuracy, the
evaluation monitored two properties of the emerging federations.
%
The federation count
%
\begin{equation}
  |\mathcal{F}^{(t)}|
  =
  |\mathcal{L}^{(t)}|
  \label{eq:psfl-federation-count}
\end{equation}
%
is the number of active leaders at round \(t\).
%
Federation correctness measures the number of devices assigned to a leader
located in a different ground-truth region:
%
\begin{equation}
  \Diamond(\mathcal{F}_j)
  =
  \sum_{d\in\mathcal{F}_j}
  \mathbb{I}
  \left[
    \xi(d)\neq\xi(l_j)
  \right],
  \label{eq:psfl-federation-correctness}
\end{equation}
%
where \(\xi(d)\) identifies the region containing device \(d\), and \(l_j\) is
the leader of federation \(\mathcal{F}_j\).
%
The ground-truth region is used only for evaluation and is not available to the
devices during federation formation.
%
A correctness value of zero therefore indicates that a federation contains
only devices sharing the same underlying data distribution.

For the mobility experiment, a binary leader-change indicator was also used to
record whether the moving device changed federation between two consecutive
time steps.

Federation formation exhibits a clear dependence on the selected threshold.
%
With \(\sigma=20\) and three relatively large regions, the system often
stabilizes around five federations instead of three.
%
Nevertheless, federation correctness remains zero: some regions are divided
into multiple federations, but devices with incompatible distributions are not
grouped together.
%
This finer partition does not produce a measurable degradation in final model
accuracy.

With \(\sigma=40\), federation count and correctness converge to the expected
configuration after an initial transient.
%
Conversely, with \(\sigma=80\) and nine smaller regions, the coarser threshold
can allow devices from distinct regions to be grouped into the same federation,
resulting in a small nonzero correctness error.
%
These findings answer \ref{rq:psfl-clustering} positively while showing that
\(\sigma\) controls a trade-off between splitting compatible devices into
multiple federations and merging devices with incompatible distributions.

The non-clustered baselines deteriorate as the number of regions, and therefore

FedProx and Scaffold improve slightly over \gls{FedAvg}, but they still optimize

\paragraph{\ref{rq:psfl-mobility}: Adaptation to device mobility}

The mobility experiment evaluates whether federation formation can adapt when a
new device moves through an already stable system.
%
As shown in \Cref{fig:psfl-movement}, movement produces only temporary
instability.
%
After each transition, the validation loss returns to a low value, the
leader-change indicator stabilizes, and the federation count returns to nine.

When entering a new region, the moving device may initially attempt to create a
new federation.
%
As the local dissimilarity estimates stabilize, it joins a compatible existing
federation without disrupting the surrounding organization.
%
These results answer \ref{rq:psfl-mobility} positively.
%
Because leader election and region formation are continuously recomputed using
the current models and communication topology, \gls{PSFL} can update federation
membership as devices move while preserving the stability of the learning
process.

Overall, \gls{PSFL} removes the strict spatial-data correlation assumption
required by \gls{FBFL} and discovers data-compatible federations without knowing
their number in advance.
%
This flexibility requires neighboring devices to exchange and evaluate dense
models when computing their loss-based distance.
%
The resulting computational and communication costs motivate the sparsified
extension presented in the following section.
